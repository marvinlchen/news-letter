# A股板块领先信号 v0.2-H：策略冻结说明

| 项目 | 内容 |
|---|---|
| 版本 | v0.2-H（历史代理版） |
| 冻结日期 | 2026-07-15 |
| 研究对象 | 申万一级行业及其产业链 |
| 用途 | 对与 v0.1 完全相同的六个历史节点做同样本反事实复核 |
| 文档状态 | 规则冻结；尚未完成全行业样本外验证 |

> v0.2 是在阅读 v0.1 同一批样本的结果后提出的，存在明确的数据窥探与规则拟合。本轮只能检查新规则能否按预期修正已知错误，不能估计真实未来命中率，也不构成投资建议。

## 一、这次调整解决什么问题

v0.1 把“发现产业改善”和“可以交易”混在同一结果中，容易出现两类错误：

1. 产业方向最终正确，但未来20—60日仍然跑输，例如2025-02-28的通信；
2. 证据继续变强时，行情已经越过主要启动阶段，例如2025-08的通信、电子和有色。

v0.2 将系统拆成两个独立目标：

- **证据雷达层：** 只回答产业改善是否得到足够硬证据，优先保留领先时间；其中“早期雷达”只是证据通过但市场尚未确认的一种状态；
- **交易激活：** 只从已通过证据门的行业中选择市场开始确认、质量可接受且没有明显追高风险的候选。

覆盖由证据雷达层负责，条件精度由激活层负责。两者分别验收，不能用一个总分掩盖取舍。

## 二、v0.2-H 与 v0.2-F

完整的前瞻版本称为 v0.2-F；本次历史回放使用 v0.2-H。

| 模块 | v0.2-F 前瞻版 | v0.2-H 历史代理版 |
|---|---|---|
| 证据门 | 全行业时点数据库 | 对四条已审计产业链做时点重建 |
| 市场确认 | 相对收益、行业宽度、成交占比三选二 | 过去20日收益大于0，且横截面排名前12 |
| 拥挤 | 历史估值、换手、持仓和涨幅分位 | 年内+30%、上一年延续拥挤、短期急涨三个可重建条件 |
| 运行频率 | 每周 | 六个季度间隔抽样节点 |
| 验证性质 | 冻结后前瞻 | 同样本反事实复核 |

历史代理不能替代完整版本。它只在缺少历史宽度、成交占比和估值自身分位时，提供一个可审计的保守近似；证据延续仍含人工判断。

## 三、信息时点

本轮统一在节点日收盘后批处理，信息截止时间为节点日23:59（中国标准时间），并从下一交易日执行。节点日盘后、但在23:59前发布的公告可以纳入；无法确认精确发布时间的公告按节点日盘后可得处理，同样只能从下一交易日执行。

后续20日/60日收益和行业最终排名只用于事后评价。节点信息截止前是否已经触发 E30 属于当时可见输入，可以进入防追高判定；节点之后的首次 E30 日期只能用于后验领先期评价。

为与 v0.1 保持可比，本轮后验收益仍从节点收盘计算，因此只是横截面诊断，不是可成交收益。正式 v0.2-F 必须从下一交易日实际可成交价格起算，并计入滑点与费用。

本报告中的 E30 定义为：行业指数相对上一年最后交易日收盘首次上涨至少30%。它是当时可观察的年内绝对涨幅阈值，不依赖事后年度最终收益。

## 四、硬证据门

每条产业链先审计三类证据：

| 维度 | 主要字段 | 典型行业 |
|---|---|---|
| S：供需 | 产品价格、库存、有效产能、开工率、价差 | 有色、化工、建材 |
| O：订单 | 在手订单、合同负债、利用率、交付周期、客户资本开支 | 通信、机械、电力设备 |
| E：盈利扩散 | 两家以上公司的收入、毛利率、利润和经营现金流 | 电子、消费、医药 |

升级为 PASS 必须同时满足：

1. S/O/E 三类中至少两类改善；
2. 至少有第二家公司，或上游—下游/客户—供应商的独立复核；
3. 证据具有明确发布日期并满足时点约束。

政策、媒体叙事、单家公司或单纯低基数不能单独形成 PASS。按这个新门槛，2025-02-28通信虽然有中际旭创业绩快报，但缺第二家公司或上下游复核，因此由 v0.1 的 PASS 降为“证据观察”。

### 4.1 v0.2-H 的证据保鲜与年度口径

本轮没有逐条字段级有效期数据库，只能冻结一个历史代理：

1. 每个 PASS 至少有一项核心硬证据在节点前180个自然日内更新；
2. 独立复核链必须仍然存在，且没有更晚的A/B级相反证据；
3. 旧证据只能作为产业链背景，不能单独刷新 PASS；
4. 2025全年与2026上半年分别作为两个目标期，领先期从目标期开始后的固定节点重新验证，不把上一目标期的旧PASS直接当成新目标期首次覆盖。

第2项仍含人工审计判断，这是 v0.2-H 不能称为完全机械回测的原因之一。v0.2-F 必须给不同字段设定明确有效期并保存每周证据快照。

## 五、质量层

完整版本对证据分实施以下惩罚：

| 质量旗标 | 惩罚 |
|---|---:|
| 经营现金流没有同步改善 | -10 |
| 一次性收益、并购口径或低基数主导 | -10 |
| 结论集中于单家公司 | -8 |

v0.2-H 没有完整历史基础分，不能伪造精确总分，因此冻结为：

- 一个实质质量旗标：保留候选但排序扣分；超过三个新激活时排在无旗标候选之后；
- 两个及以上实质质量旗标：失效，不得新激活；
- 单公司集中若同时导致缺少独立复核，直接在证据门被拦截。

质量问题与拥挤问题分开记录，避免把基本面恶化错误解释成“只是涨多了”。

## 六、市场激活

### 6.1 v0.2-F 完整规则

已通过证据门的行业满足下列三项中的两项，才可激活：

1. 20日相对收益转正或连续改善；
2. 站上60日均线的成分股比例连续两周上升；
3. 成交额占比上升，但低于自身历史85%分位。

### 6.2 v0.2-H 历史代理

由于本批历史数据缺少时点化行业宽度和成交占比，本轮冻结为：

~~~text
过去20日行业收益 > 0
并且
过去20日收益在31个申万一级行业中排名 <= 12
~~~

两项必须同时成立。这个代理比完整规则更依赖价格，报告中必须显式标注，不能把它包装成已经完成的市场广度检验。

## 七、防追高与延续拥挤

证据门通过后，只要触发以下任一条件，就不再“新激活”：

1. **周期成熟：** 本自然年已经触及 E30；该状态锁存至年末；
2. **上一年延续拥挤：** 上一完整自然年行业涨幅至少50%，且当前过去20日排名前8；
3. **短期急涨：** 当前过去20日排名前3，且绝对涨幅至少15%。

这些条件只表示“禁止新增”，不等于看空，也不自动产生卖出信号。E30、排名和短期涨幅是相关指标，因此不重复累计成多个拥挤分数。

“此前已激活”只在当前激活周期内判断。新激活开启周期；E30、失效或自然年末关闭该周期。E30状态锁存到当年末，下一自然年重置后，行业若重新满足全部条件，可以再次记为新激活。因此2025通信周期关闭后，2026-02通信属于新的年度激活，而不是跨年持有确认。

## 八、状态机和判定顺序

判定严格按以下顺序执行：

~~~text
证据门不通过
  → 证据观察

证据门通过，但有两个及以上质量旗标
  → 失效

证据门通过，但触发防追高
  → 周期成熟 / 延续拥挤

证据门通过、没有否决，但市场代理不通过
  → 早期雷达

证据门、市场代理均通过且没有否决，且此前已激活
  → 持有确认

证据门、市场代理均通过且没有否决，且此前未激活
  → 新激活
~~~

每个节点最多三个新激活。超过上限时，先比较证据质量，再比较市场横截面排名。

## 九、行业专用证据模板

| 类型 | 必须优先观察 | 常见伪信号 |
|---|---|---|
| 价差型：有色、化工、建材 | 价格/价差、库存、产能、现金成本、现金流 | 只有涨价，但库存与供给同步增加 |
| 订单型：通信、机械、电力设备 | 客户资本开支、订单、合同负债、交付、利用率 | 单个大单或单家公司口径 |
| 产品周期型：电子、消费电子 | 渗透率、排产、良率、ASP、客户扩散、毛利率 | 概念热度先于订单和利润 |

同一一级行业必须标记真正驱动细分。例如建筑材料需要区分水泥地产链与玻纤/电子布，不能用一级行业名称代替利润机制。

## 十、后验评分

| 状态 | 评价方法 |
|---|---|
| 证据层PASS及以上 | 是否在目标行业触及 E30 前出现；记录领先交易日 |
| 新激活 | 未来60个交易日行业收益是否进入31行业前8；未来20日为辅助指标 |
| 持有确认 | 单列后续20/60日表现，不重复进入“新激活”分母 |
| 周期成熟/拥挤 | 记录机会成本，不按失败处理 |
| 无信号 | 不进入成功或失败分母 |
| 结果未成熟 | 标记未完成，不能提前判为失败 |

本轮只审计四条目标相关产业链，不能计算全市场正式 Precision、Recall、组合收益、Sharpe 或最大回撤。

## 十一、冻结后的验收要求

下一阶段应将 v0.2-F 固定后：

1. 对31个申万一级行业每周统一评分，而不是只复核已知赢家；
2. 保存原始输入、available_at、候选全集、状态和规则版本；
3. 至少累计20次独立新激活，再评价条件精度；
4. 同时报告雷达覆盖、激活覆盖、领先期、假阳性率和候选数量；
5. 规则冻结期内不因单次错判改阈值，变更必须升级版本并重新开始样本外计数。

本轮历史结果见 [v0.2-H 六节点同样本反事实复核](./a-share-sector-backtest-samples-v0.2/README.md)。
