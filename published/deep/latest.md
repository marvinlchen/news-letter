- **来源：** Google Cloud Blog

### 4. Cloud Run上的Temporal Serverless Worker：让worker先行于需求扩缩

- **原标题：** Temporal Serverless Workers on Cloud Run: Scale workers ahead of demand
- **来源：** Google Cloud Blog
- **发布时间：** 2026-10-15T16:00:00+00:00
- **原文：** https://cloud.google.com/blog/products/serverless/temporal-serverless-workers-on-cloud-run-worker-pools
- **推荐理由：** 针对Temporal worker“拉任务而非接请求”与请求驱动型Serverless平台不匹配的经典矛盾，给出Cloud Run worker pools方案与权衡，对编排类和智能体工作负载的部署选型很有价值。
- **核心问题：** Temporal worker以轮询方式拉取任务，难以适配请求驱动的Serverless平台，团队被迫在Kubernetes或虚拟机上常驻worker集群，自建指标管道与扩缩容触发器，扩容滞后于突发流量，且无论队列是否有任务都要持续付费。
- **关键思路：** 用Cloud Run worker pools承载这类拉取型工作：实例连接到队列或流并主动取下一个任务处理，从而在需求到达前完成扩容，替代常驻集群加自建指标与调参的方案。
- **工程启示：** 对队列或流驱动的消费者型工作负载，应优先选择原生支持拉模型的Serverless形态，而不是把请求驱动平台硬套在轮询worker上，可省去常驻成本并缓解扩容滞后。
- **局限与待验证项：** 候选文本在实例取任务处截断，缺少冷启动、并发模型与版本兼容细节，也未见基准测试数据与成本对比。

### 1. REKI：在视觉-语言-动作模型中注册知识

- **原标题：** REKI: Registering Knowledge in VLAs
- **来源：** arXiv AI
- **发布时间：** 2026-10-15T16:34:06+00:00
- **原文：** https://arxiv.org/abs/2610.22178v1
- **推荐理由：** 一个仅用公开数据预训练的2.4B视觉-语言-动作模型，在多个仿真基准与真实机器人上给出性能与规模的帕累托前沿，并给出明确的量化收益，是少见的“小模型加记忆机制”扎实实证工作。
- **核心问题：** 视觉-语言-动作模型的性能提升通常依赖参数规模扩张，如何在仅用公开数据、较小参数量的条件下取得接近约两倍规模模型的表现，并抑制策略在不同姿态间来回振荡。
- **关键思路：** 模型由视觉语言模型加流匹配动作专家组成，在机器人、第一人称人类与视觉-语言数据的混合上预训练；在动作专家中引入少量register token作为记忆，逐帧摘要视觉语言模型输出并保留在专家缓存中，以极低代价让策略获取近期历史。
- **工程启示：** 用极小的register-token记忆换取长程一致性，是比堆参数更经济的改进路径；这种几乎不增加推理成本的记忆机制对机器人策略部署具备工程可行性。
- **局限与待验证项：** 候选数据只给出摘要前半部分，缺少完整训练配置、各基准具体分数、真实机器人实验规模与失败案例分析；记忆机制的收益主要体现为振荡减少，泛化边界无法从候选数据中得到验证。

- **来源：** arXiv AI
