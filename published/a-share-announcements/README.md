范围和版式遵循用户提供的《10月11日-A股重大公告利好利空日报交付标准》，触发时间按用户要求改为05:00。公告来自东方财富全量索引和巨潮官方披露，行情截至公告日收盘；iFinD等付费插件尚未配置，未核实字段标为“数据待核”。
