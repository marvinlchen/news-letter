# A股重大公告利好利空日报

每天05:00（中国/新加坡时间，UTC+8）处理前一自然日的沪深A股重大公告；周末及节假日均照常生成并上传，不按交易日跳过；当日没有符合重大性标准的公告时，日报会明确说明。

日报生成后，本目录保存 `YYYY-MM-DD.md` 和同日结构化JSON，`latest.md`为最新成功日报，自动提交并推送GitHub main。

内容范围沿用用户提供的《10月11日-A股重大公告利好利空日报交付标准》，按2026-10-18最新要求改为Markdown交付。逐股包含公告、事件分析、关键数据、技术面、来源与待核字段。公告来自东方财富全量索引和巨潮官方披露，iFinD按公告日检索交叉核验；行情使用不晚于公告日的最近有效收盘数据并注明实际日期，未核实字段标“数据待核”。
